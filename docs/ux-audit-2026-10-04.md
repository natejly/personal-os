# UX and agent-handoff audit — 2026-10-04

Nine read-only audits, one per feature cluster, against main `bccf252`. The full per-cluster reports
(inventory tables, orphans, file:line evidence) were written outside the repo; this is the synthesis, what
branch `worktree-ux-agent-handoff` changed, and what is left.

## What the audits found

**Scale.** 15 views, 12 Settings tabs, 15 Today cards, 156 agent tools, ~347 HTTP routes. Most features are
reachable; the problem is *where agent work comes back*, not whether features exist.

**Agent work landed in about twelve places, several hidden by default.**

| Waiting on the user | Where it surfaced before | Visible by default? |
|---|---|---|
| Approval cards | each chat's transcript, plus the Agent inbox | yes |
| Job proposals, paused jobs, job runs | Agent inbox (Today) | yes |
| Desks needing you / in review | Cowork view, Today Cowork card | **no** (both off) |
| Desk outputs to accept | the desk's Output tab | **no** |
| Skill candidates, workflow runs, agent defs | Library | **no** |
| Proposed doc edits | Files sidebar badge | yes |
| Meeting notes to review | Meetings badge | **no** |
| Memory tidy-ups | Memory list view, no badge | buried |
| Activity suggestions | Activity → Insights tab | **no** |
| Queued mail (undo window) | toast stack | only on launch (bug) |

**Handoff between agents was text-only and one-way.** `desk_start` took a title and a brief; a chat could not
pass files in, desks had no record of the chat that started them, and nothing told that chat when the desk
finished. A desk could not reach another desk's files; the only bridge was the user promoting an output to a doc.

**Unsafe or broken paths found on the way.**
- Allow in the Agent inbox on a `propose_plan` card approved every step unseen; on `desk_ask` it answered
  with no text, so the question was lost.
- Inbox Allow/Deny silently did nothing when no chat was focused, and never refreshed the list.
- Desk OS notifications only fired after Cowork had been opened once in the session.
- The desk header's "Accept all" sent every output to a new personal doc, ignoring the destination and
  project chosen on the Output tab.
- Eight "Connect Google" buttons opened Settings on the Provider tab; the context drawer's skills "review"
  link opened Settings although skills live in Library.
- ⌘B (bold) and ⇧⌘M (maths) never reached the doc editor: the menu took them (sidebar, Meetings).
- Accepting a `gmail_send` proposal toasted "that one actually ran" for mail that was only queued, and the
  undo countdown did not appear for mail queued after launch.
- Dashboard widgets placed on a space showed an error (a guard on an id that was never used); `widget_place`
  crashed with no spaces and ignored a locked space; agent edits to a space never appeared live.
- `GET /conversations/{id}/plan` was registered twice; the second never ran.
- The daily recap made a model call at every launch even with its card off.

## What this branch changed

- **One inbox.** `/inbox` adds desks waiting on the user (one row per desk, deduplicated against their
  approvals) and an `elsewhere` list: a count and a link for doc edits, meeting notes, skills, workflow runs,
  memory tidy-ups and activity suggestions. The sidebar's Today row carries the total. Plan and `desk_ask`
  cards, and any desk's card, show **Open** instead of a blind Allow. A failed desk now reaches the inbox.
- **Handoff primitive.** `desk_start` takes `doc_ids`, copied into the desk's `inputs/` before its first turn,
  and records the calling chat (`desks.origin_conversation_id`). On `review`, `done` or `failed` the desk
  posts its report — status, note and outputs — into that chat as an assistant turn, so the chat's agent
  reads the result on its next reply. The chat card links to the desk.
- **Visibility.** Cowork and Library ship visible (`modulesDefault` 4 unhides them once). Meetings and
  Activity stay off: they record.
- **Desk review.** The header shows "Review N outputs" (opens the Output tab) instead of Accept/Reject all;
  outputs start ticked; a promoted doc is a link; Archive is not offered while outputs are undecided.
- **Fixes** for every item in the list above.

## Backlog, ranked by value ÷ effort

1. **Permissions in one place.** 13 surfaces write 6 stores (global/project/chat tool modes, permission
   rules, in-memory session grants, MCP grants in three scopes, job allowlists, desk autonomy). The approval
   card can show seven buttons (`GenericApproval` + `ApprovalRules`). Pick one grant vocabulary and one
   Settings tab that lists every standing grant with revoke. M.
2. **One Files.** Docs, uploads ("Documents" / "Knowledge base"), artifacts and Library → Made are four
   homes for documents with four names; `search_documents` already treats docs and uploads as one corpus.
   Merge into Files with type tags (Note / Upload / Page); delete Made. L.
3. **Settings 12 → 8 tabs.** Knowledge base + Memory & learning; Trash and diagnostics into Data; delete the
   Spaces tab (two selects that only work inside a space); search keys into Integrations. S–M.
4. **Command palette (⌘K).** No global palette exists; Files, Library, Mail, Health, Projects and the inbox
   have no shortcut. ⌘K is the editor's link chord, so the palette needs another chord or an editor-aware
   handoff like the ⌘B fix. M.
5. **Desk outputs beyond docs.** A desk can only promote to a doc, an upload or a download — not a todo, a
   mail draft, a calendar event or an artifact. Route these through the existing proposal tools. M.
6. **Workflow runs report back** to the chat that proposed them (`workflow_runs.conversation_id` is stored
   but unused), the same way desks now do. S.
7. **Planner duplication.** Today's Day-plan card, Todos "Plan my day", Calendar "Plan my week" and
   `schedule_suggest` are four schedulers; keep one that ends in a `calendar_propose` card. M.
8. **Google Tasks duplication.** With two-way sync on (the default), Todos and the Google Tasks card and
   tools show the same items twice; hide `google_tasks_*` and the card while sync is on, and say before
   sign-in that sync and a "Grain Todos" calendar are created. S.
9. **Delete orphans.** Routes with no caller: `/mail/watch/config`, `PUT /mail/watch/{id}/snooze`,
   `/planner/config`, `/integrations/google/{cache,tasks,drive}`, nine meetings/activity routes,
   `/cowork/desks/{id}/events|outputs`, `/cowork/plans/{id}`, board claim/release; dead `useCanvas.openChat`.
   S.
10. **Canvas onboarding.** Spaces (~8.7k lines) are never explained before you are inside one, and
    `docs/canvas-mode.md` still says "nothing built yet". One sentence in onboarding and the sidebar
    section; replace the design docs with a one-screen feature doc. S.
