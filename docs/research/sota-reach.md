## Web search/fetch, Agent Reach, Python sandbox, MicroVMs and Mac reach

### Where we are

**Web fetch.** `fetch_url` (tools.py ~L682, inside `_register_*` web block) does: `_check_url` (scheme, no creds, literal-IP SSRF, taint allowlist via `_norm_url`/`_allowed_urls`) then `_resolve` (all A/AAAA public), manual redirect loop (max 5, each hop re-validated), `httpx.get`, then `trafilatura.extract(output_format="markdown", include_links=False, include_tables=True)` with a regex tag-strip fallback. If status in 401/403/429/503, or text <300 chars on an HTML page, and `readerFallback` is true (llm.DEFAULT_SETTINGS), it retries through `reach.jina_read` (r.jina.ai) and keeps the longer text. Output is `{url,status,content_type,text,truncated,redirects,via?}`, `text` clipped to max_chars (1000..40000). Weak spots verified in code: (a) it always reads `r.text` regardless of content-type, so a PDF, JSON or binary response is decoded as garbage even though `extract_text.py` already handles PDFs (pypdf) for uploads; (b) links are discarded (`include_links=False`), so the model cannot follow a page's links without a second search; (c) no offset paging: truncation at 40k chars is final (other tools such as `read_local_file` and `sandbox_read_file` do have offset); (d) no query-focused trimming, so a long page spends the whole 12k budget on the top of the page; (e) no cache, so a plan that re-reads the same URL re-fetches it (and re-hits Jina).

**Web search.** `web_search` picks Brave (key) > Tavily (key) > keyless Exa MCP (`reach.exa_search`, SSE parse in `parse_exa_mcp`) > DuckDuckGo (`ddgs`). Exactly one provider answers; no merging, no dedup, no `time_range`/`site` filter, no way to point at a self-hosted SearXNG. Results are `_allow_url`-registered so tainted runs can still fetch them. Output is paged with `page()`.

**Agent Reach (reach.py, 411 lines).** `jina_read`, `exa_search`, YouTube (`youtube_video` via yt-dlp, `parse_json3`/`parse_vtt` into timestamped transcript every 30s, `youtube_search`), GitHub (`github_search`, `github_read` with `gh_token` fallback to `gh auth token`), RSS (`parse_feed`). Tests in tests/test_reach.py monkeypatch every client.

**Python sandbox (sandbox.py).** `run_python`: temp work dir per call, `python -I`, rlimits applied one at a time (`_limits`), macOS `sandbox-exec` SBPL profile (`_mac_profile`) with network denied, read allowlist, secrets denied, writes confined to the work dir; matplotlib font cache warmed outside the sandbox and copied in; images returned as data URIs (`_collect_images`, 6 images, 3MB). Stateless by design: nothing survives a call, no persistent interpreter, no pip.

**MicroVM sandboxes (microvm.py, `Sandboxes`).** One docker/colima container per conversation (`pos-sbx-<sha1[:12]>`), `--network none` unless `sandboxNetwork`, `--cap-drop ALL`, `no-new-privileges`, 1g/2 cpu/256 pids, `sleep infinity`, `timeout -k 5` wrapping every exec, LRU reap at 5, tools `sandbox_exec/write_file/read_file/list_files/put_document/reset`, networked results taint the run, `desk_import_sandbox` bridges to desk workspaces. Weak spots: `shutdown()` does `rm -f` on every labeled container, so all state in `/workspace` and any apt/pip install is lost at every app quit; there is no checkpoint/rollback, so a wedged or half-installed environment can only be `sandbox_reset` (total loss); read/write is text-only (no binary file out to the user besides images); no port exposure; no `Sandboxfile`-style per-project image/setup.

**Mac reach (mac.py, src/main/pagefetch.ts).** `mdfind` (Spotlight) `find_files`, `read_local`, home-scoped `write_local/move_local/trash_local` (ask-first, `files` group), `list_shortcuts`/`run_shortcut` (`shortcuts run --output-path`, 60s default, input via stdin, output via `extract_text`), `PageBridge.open_page` to a loopback Electron bridge that loads a hidden BrowserWindow in `persist:agent` (private network blocked via `webRequest`, permissions denied, `will-download` prevented, 700ms settle, innerText of main/article or body). Read-only, no clicks, per standing anti-goal. Weak spots: `open_page` returns flat innerText (no links, no structure), no `wait_for_selector`/scroll for lazy pages, no Shortcut input beyond text.

### What the best open-source systems do

**Crawl4AI** ([markdown generation docs](https://docs.crawl4ai.com/core/markdown-generation/)). Two outputs per page: `raw_markdown` and `fit_markdown`. Fit comes from a content filter: `PruningContentFilter` scores DOM blocks on text density, link density and tag structure with `threshold` (0-1, fixed or dynamic) and `min_word_threshold` to drop short blocks; `BM25ContentFilter(user_query, bm25_threshold, use_stemming)` ranks blocks against a query and keeps the relevant ones. `DefaultMarkdownGenerator` converts links into numbered citations (`[text][1]`) and emits a `references_markdown` list at the bottom, so link-heavy pages cost far fewer tokens and the model still gets the URLs.

**Firecrawl** ([scrape docs](https://docs.firecrawl.dev/features/scrape)). Multi-format response (`markdown, html, links, summary, json` with schema or prompt, `screenshot`), `onlyMainContent`, `includeTags/excludeTags`, `actions` (click, write, press, wait) before extraction, and a `maxAge` cache (default 2 days, `maxAge:0` forces fresh). Separate `map` (list a site's URLs) and `crawl` endpoints.

**Jina Reader** ([github.com/jina-ai/reader](https://github.com/jina-ai/reader)). Header-driven: `X-Target-Selector`, `X-Remove-Selector`, `X-Wait-For-Selector`, `X-With-Links-Summary` (deduplicated link footer, optionally with `X-Retain-Links: text`), `X-Token-Budget` (reject over budget) and `X-Max-Tokens` (truncate), `X-No-Cache` (default 3600s page cache), `X-Engine: browser|curl|auto`, PDF via PDF.js and Office docs via LibreOffice. `s.jina.ai` = search, then fetch the top 5, then read each, returning full content rather than snippets.

**SearXNG** ([search API](https://docs.searxng.org/dev/search_api.html)). Metasearch: `GET /search?q=&format=json&categories=&engines=&time_range=day|month|year&pageno=&language=`, passes native operators like `site:` through, and merges and scores duplicates across engines. Self-hostable, no keys, the standard keyless backend in open agent stacks.

**Stagehand** ([extract docs](https://docs.stagehand.dev/v3/basics/extract)). Extraction runs over the accessibility tree rather than raw HTML, takes a JSON/Zod schema and optional `selector`/`ignoreSelectors` to shrink LLM context, optional screenshot, and caches results for identical inputs so repeat calls cost no tokens. **browser-use** (github.com/browser-use/browser-use) is the same family: indexed interactive elements plus an action set; its internals were not in the README I fetched, so I did not rely on them. We will not copy the action half (anti-goal: no pixel or click computer use).

**E2B** ([persistence docs](https://docs.e2b.dev/sandbox/persistence)). Sandbox states running/paused/snapshotting/killed; pause saves filesystem and memory (about 4s per GiB), resume about 1s via `connect()`, `keepMemory:false` for filesystem-only, `onTimeout:'pause'` auto-pause instead of kill. The code-interpreter variant keeps a Jupyter-style kernel so variables persist across cells.

**microsandbox** ([github.com/microsandbox/microsandbox](https://github.com/microsandbox/microsandbox)). libkrun microVMs, sub-100ms boot, OCI images, persistent named sandboxes, fork and snapshot ("save running sandbox state and restore later"), network policies, secrets that never enter the VM, MCP server. **Daytona** and Docker sandboxes are the same shape with stop/start (not delete) as the default lifecycle and snapshots as images. **Open Interpreter** (current Rust fork of Codex, github.com/OpenInterpreter/open-interpreter) relies on native OS sandboxing plus approval before execution, which is the posture we already have.

**macOS automation.** Shortcuts CLI (`shortcuts run -i/-o`) is what we use; AppleScript/JXA runners exist in open projects but would let an agent act outside the app with an arbitrary script, so we keep Shortcuts-only (user-authored, user-scoped).

### Specs

#### web-1: fetch_url pipeline: content-type routing, numbered link citations, BM25 focus, offset paging, TTL cache (M)

**Why.** Highest-impact gap in the fetch path. Crawl4AI emits fit_markdown (BM25ContentFilter(user_query)) and numbered-citation markdown with a references list; Jina Reader parses PDFs and appends a deduplicated links summary and caches pages for 3600s (X-No-Cache bypass); Firecrawl exposes a links format and maxAge cache. Today fetch_url decodes every body as text (PDF becomes garbage though extract_text.py already reads PDFs), drops all links (include_links=False), truncates at 40k with no way to continue, and never caches.

**Files.** `backend/personal_os/webread.py (new)`, `backend/personal_os/tools.py (fetch_url only: ~30 lines)`, `backend/personal_os/db.py (web_cache table)`, `backend/personal_os/llm.py (DEFAULT_SETTINGS)`, `backend/tests/test_webread.py (new)`

**Design.** 1) db.py: add `CREATE TABLE IF NOT EXISTS web_cache (url TEXT PRIMARY KEY, fetched_at REAL NOT NULL, status INTEGER, content_type TEXT, body BLOB, final_url TEXT)` in the SCHEMA block (same style as other CREATE TABLE IF NOT EXISTS; new table needs no _migrate). Cap rows: on insert delete rows older than 24h and, if >200 rows, the oldest. Bodies over 2MB are not cached.
2) webread.py pure functions (no network, no db):
 - `classify(content_type: str, url: str, head: bytes) -> 'html'|'pdf'|'json'|'text'|'binary'` (content-type first, then .pdf suffix / %PDF- magic).
 - `render(kind, body: bytes, text_hint: str, final_url: str, *, include_links=True) -> Rendered(text: str, links: list[{n,text,url}])`. html: `trafilatura.extract(html, output_format='markdown', include_links=True, include_tables=True)` then `numberize_links(md, base_url)` which rewrites `[text](href)` to `[text][n]`, resolves relative hrefs with urljoin, dedups by absolute URL, keeps only http(s), and returns the list; fall back to the existing regex strip if trafilatura returns empty (links=[] then). pdf: `extract_text('x.pdf', body)` from extract_text.py (ValueError -> error string 'could not read PDF'). json: `json.dumps(json.loads(...), indent=1)`; invalid JSON falls to text. binary: raise `Unreadable('binary content (<type>), cannot be read as text')`.
 - `bm25_focus(text: str, query: str, budget: int) -> str`: split on blank lines into blocks (merge blocks <40 chars into the next); tokenise lowercase `\w+`, drop stopwords (small inline set); BM25 with k1=1.5, b=0.75 over blocks (idf = ln(1+(N-df+0.5)/(df+0.5))); always keep block 0 (title/lede); take highest-scoring blocks until `budget` chars; emit in original order joined with `\n\n`, inserting `[...]` where blocks were skipped. If the query tokenises to nothing return text unchanged.
 - `page_window(text, offset, max_chars) -> (slice, total, next_offset|None)`.
3) tools.py fetch_url: add params `focus: str = ''`, `offset: int = 0`, `fresh: bool = False`, `links: bool = False`. Keep `_check_url`/`_resolve`/redirect loop exactly. After the loop and before parsing, cache lookup/store keyed by the final normalized URL (`_norm_url`) via a small `WebCache(db)` class in webread.py (constructor takes the sqlite connection getter used elsewhere in Toolbox; check how Toolbox reaches db, e.g. self.db). TTL from setting `fetchCacheSeconds` (default 3600, 0 disables; `fresh=True` bypasses). Cache is consulted only after the SSRF/taint check, so a tainted run cannot read a cached URL it could not fetch. Replace `r.text`+trafilatura block with classify/render. Jina fallback keeps its current trigger but only for kind=='html'. Output adds `kind`, `total_chars`, `next_offset` (None when done), `cached: bool`, and `links` (first 40 `{n,text,url}`) only when `links=True` or when numbered refs exist and the page is HTML (always append a `## References` list to text capped at 40 entries when links=True). `truncated` becomes `next_offset is not None`. When `focus` is set, apply bm25_focus to the full text before windowing and set `focused: True`. Link URLs returned are NOT passed to _allow_url (they are untrusted page content; tainted runs still cannot fetch them) -- this preserves the taint model.
4) llm.DEFAULT_SETTINGS: `"fetchCacheSeconds": 3600` with a comment line like the neighbors.
5) Update ToolSpec description and examples for fetch_url (focus, offset, links) and ALTERNATIVE unchanged.

**Tests.** backend/tests/test_webread.py, plain script style like tests/test_reach.py (pytest-compatible, asyncio.run, monkeypatch httpx). Cases: classify for html/pdf/json/png; render a tiny PDF built in-test (pypdf is installed; build with pypdf PdfWriter blank page + mocked extract_text if page text is hard, else monkeypatch webread.extract_text) ; numberize_links dedup, relative resolution, javascript: and mailto: dropped; bm25_focus keeps the lede and the paragraph containing the query term, preserves order, respects budget, no-op on empty query; page_window offsets; WebCache TTL expiry using injected clock, fresh bypass, size cap; end-to-end fetch_url through Toolbox with `httpx.AsyncClient.get` and `_resolve` monkeypatched returning a canned response: second call reports cached=True and makes zero network calls; tainted ctx still blocks a non-allowlisted URL even when the cache holds it; PDF bytes with content-type application/pdf return extracted text, not mojibake. #### web-2: web_search backends: SearXNG, RRF merge/dedup, time_range and site filters (M)

**Why.** SearXNG is the standard keyless/self-hosted metasearch (json API with q, categories, engines, time_range, pageno; merges duplicate results across engines); Jina s.jina.ai and Tavily/Exa expose recency and domain filters. We use exactly one provider per query (Brave > Tavily > Exa > DDG), cannot filter by recency or site, and cannot point at a user's own SearXNG. Merging two independent engines with reciprocal rank fusion is a known recall win with no extra dependency.

**Files.** `backend/personal_os/websearch.py (new)`, `backend/personal_os/tools.py (web_search body only, replace the provider if/elif with one call, add 2 params)`, `backend/personal_os/llm.py (DEFAULT_SETTINGS)`, `backend/tests/test_websearch.py (new)`

**Design.** 1) websearch.py: `@dataclass Hit(title,url,snippet,engines:list[str],score:float)`. `norm_key(url)`: lowercase host without www., drop fragment and utm_*/fbclid/gclid params, strip trailing slash, http==https. `rrf_merge(lists: dict[str, list[dict]], k=60) -> list[Hit]`: score = sum over engines of 1/(k+rank); dedup by norm_key keeping the longest snippet and the first title; `engines` records which providers returned it; sort by score desc, stable. `apply_site(query, site)` appends `site:<domain>` after validating the domain with a regex (no spaces/quotes). `TIME_RANGES = {day,week,month,year}` with per-provider mapping: Brave `freshness=pd|pw|pm|py`; Tavily `time_range`; SearXNG `time_range` (week unsupported -> month, note in result); DDG `timelimit=d|w|m|y`; Exa: append no filter (not supported on the keyless MCP; add `"time_range_ignored": True` to the result).
2) Providers as async functions `brave(cfg,q,n,tr)`, `tavily(...)`, `exa(...)` (wraps reach.exa_search), `ddg(...)` (the existing to_thread DDGS code, moved verbatim), `searxng(cfg,q,n,tr)`: GET `{searxngUrl}/search` params `q, format=json, time_range, pageno=1`, parse `results[]` (`title,url,content,engines`), 15s timeout; HTTP 403 (json disabled) raises ProviderError('SearXNG has format=json disabled; add `json` under search.formats in settings.yml'). The searxngUrl is user-configured and may be http://localhost, so it is intentionally not run through _check_url (it is not a model-chosen URL); validate scheme http/https only when saving.
3) `async def search(cfg, query, want, time_range='', site='') -> (rows, meta)`: provider order = explicit keys first (Brave, Tavily), else keyless set [searxng if searxngUrl, exa, ddg]. Keyed provider answers alone (current behavior). Keyless: run searxng (if set) and exa concurrently with `asyncio.gather(return_exceptions=True)`, rrf_merge the successes; if both fail or are empty fall back to ddg. meta carries `engines_used`, `failed` (provider -> first line of error), and `time_range_ignored`.
4) tools.py web_search: new params `time_range: str = ''` (enum day|week|month|year) and `site: str = ''`; body becomes `rows, meta = await websearch.search(...)`; keep the `for row in rows: _allow_url(ctx,row['url'])` loop and `page(rows, ...)`; return the page dict plus `meta` keys. Result rows keep `{title,url,snippet}` and add `engines` only when merged.
5) llm.DEFAULT_SETTINGS: `"searxngUrl": ""` (empty = off) with a comment; no UI required (Settings JSON tab already exposes settings if present; if a Settings field list exists in src/renderer, add one text input beside exaApiKey).

**Tests.** backend/tests/test_websearch.py: norm_key collapses utm params, www, trailing slash, scheme; rrf_merge ranks a URL returned by two engines above single-engine top hits, keeps the longest snippet, records engines; time_range mapping per provider (pure function); apply_site rejects 'a b' and quotes; searxng parse from a canned JSON fixture including a result with missing content; searxng 403 maps to the ProviderError message; search() orchestration with provider functions monkeypatched: keyed Brave answers alone and calls nobody else; keyless merges searxng+exa; exa raising falls through to searxng alone; all failing falls back to ddg; web_search tool via Toolbox registers every result URL with _allow_url (tainted ctx can then fetch it). Everything monkeypatched, no network, no model.

**Done when.** With searxngUrl set and a fake server fixture, web_search returns de-duplicated merged results with `engines`; time_range='week' reaches the provider with its native parameter; site='sqlite.org' yields only a query with site:sqlite.org; with no settings changed behavior is identical to today (Exa then DDG) and tests/test_reach.py plus tests/test_source_fetch_guard.py still pass; searxngUrl persists through PUT /settings.

#### sbx-1: Persistent, checkpointable MicroVM sandboxes (stop-not-remove, checkpoint/restore) (M)

**Why.** E2B pause/resume, microsandbox fork/snapshot, and Daytona stop/start treat sandbox state as durable and recoverable. Ours is destroyed on every app quit (Sandboxes.shutdown does `rm -f` on every labeled container) and the only recovery from a broken environment is sandbox_reset, which discards everything. Checkpoints let the agent try a risky install and roll back, and persistence stops re-installing packages every session (only matters when sandboxNetwork is on).

**Files.** `backend/personal_os/microvm.py`, `backend/personal_os/tools.py (two new tool registrations next to sandbox_reset, ~25 lines)`, `backend/personal_os/llm.py (DEFAULT_SETTINGS)`, `README.md (MicroVM sandboxes section: lifecycle sentence)`, `backend/tests/test_microvm_checkpoints.py (new)`

**Design.** 1) microvm.py: constants `CKPT_REPO = 'pos-sbx-ckpt'`, `MAX_CKPTS = 3` per conversation, `STALE_DAYS` from setting `sandboxKeepDays` (default 14). Checkpoint image tag: `pos-sbx-ckpt/<name12>:<slug>` where name12 is the existing `_name(conversation_id)` suffix and slug is `re.sub(r'[^a-z0-9_.-]','-',label.lower())[:40]` (empty label -> `ckpt-<unix>`).
2) `shutdown()`: replace `rm -f` with `stop -t 3` for each labeled running container (state kept). Add `_reap_stale(binary)` called from `ensure()` before `_reap`: for labeled containers whose `{{.State.FinishedAt}}` is older than sandboxKeepDays, `rm -f` them (parse the RFC3339 timestamp with datetime.fromisoformat after trimming nanoseconds; unparseable = keep). MAX_SANDBOXES LRU reaping stays; stopped containers count toward it.
3) `checkpoint(conversation_id, label='') -> dict`: `name = self.ensure(cid)`; run `[bin,'commit','--pause=true','-m','pos checkpoint', name, tag]` (timeout 300); on non-zero raise SandboxError(_line(stderr)). Then list existing tags via `[bin,'images', CKPT_REPO+'/'+name12, '--format','{{.Tag}}\t{{.CreatedAt}}']`; if more than MAX_CKPTS remove oldest with `[bin,'rmi',tag]`. Return `{checkpoint: slug, tag, kept: [...slugs], note: 'filesystem only: running processes are not saved'}`. Docker commit does not include network mode, so networking is decided at restore from current settings.
4) `checkpoints(cid) -> {checkpoints:[{label,created}]}`.
5) `restore(cid, label) -> dict`: resolve tag (SandboxError 'no checkpoint named X; have: a, b' otherwise); `rm -f` the conversation container; `_forget(name)`; create via the same args builder as ensure() but with `image=tag` (refactor the `args=[...]` construction in ensure() into `_run_args(name, image, net)` so both paths share caps/limits/network flags); probe shell; return `{restored: slug}`. Because restore recreates with current settings, a checkpoint made while networked cannot silently re-enable the network.
6) `reset()` additionally removes that conversation's checkpoint images (`rmi -f` each) so 'reset' keeps meaning 'start clean'.
7) tools.py: `sandbox_checkpoint(label: str='')` (group 'sandbox', danger 'executes', same `_mark` taint wrapper as siblings; also lists existing when label is empty and `list=true`? keep simple: separate `sandbox_checkpoints` is NOT added; instead `sandbox_checkpoint` returns kept list) and `sandbox_restore(label: str)`. Add both names to ALTERNATIVE with sensible fallbacks (e.g. restore -> 'sandbox_reset to start fresh'). They only appear when `sb.available()` like other sandbox tools. Mention in the sandbox_reset description that checkpoints can be restored instead.
8) llm.DEFAULT_SETTINGS: `"sandboxKeepDays": 14`.
9) README MicroVM section: replace 'removed on app shutdown' with 'stopped on app shutdown and kept for sandboxKeepDays'.

**Tests.** backend/tests/test_microvm_checkpoints.py using Sandboxes(settings_fn, runner=fake) where `fake(argv, input=None, timeout=...)` is an in-memory docker simulator recording argv and returning CompletedProcess (follow how an existing microvm test, if any, or tests/test_mac_tools.py stubs subprocess). Cases: shutdown issues `stop` and never `rm` for running labeled containers; _reap_stale removes only containers whose FinishedAt is older than the window and keeps unparseable ones; checkpoint runs `commit` with the expected tag and prunes to MAX_CKPTS oldest-first via `rmi`; commit failure surfaces as SandboxError with the docker error line; restore unknown label lists available ones; restore removes the old container then runs `run` with image==tag and `--network none` when sandboxNetwork is false even if the checkpoint was made while it was true; reset removes checkpoint images; slug sanitising. No docker, no network, no model.

**Done when.** With docker available: write a file, sandbox_checkpoint('clean'), delete the file, sandbox_restore('clean') and the file is back; quitting and relaunching the app keeps /workspace contents; a 4th checkpoint evicts the oldest; restore never changes the network setting; sandbox_reset also drops checkpoints; all new offline tests pass and existing sandbox tests are unaffected.
